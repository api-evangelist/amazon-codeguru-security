# Amazon CodeGuru Security

> Amazon CodeGuru Security is a static application security testing (SAST) service that uses program analysis and machine learning to detect security policy violations and vulnerabilities in source code and infrastructure-as-code, and to recommend remediations. - [Amazon CodeGuru Security API](https://docs.aws.amazon.com/codeguru/latest/security-api/Welcome.html): REST API for creating scans, retrieving findings and metrics, managing account configuration and tags. ## Operations

- BatchGetFindings: Return a list of all requested findings.
- CreateScan: Create a scan using code uploaded to an S3 bucket.
- ListScans: List all standard scans in an account.
- CreateUploadUrl: Generate a pre-signed URL and headers to upload a code resource.
- GetAccountConfiguration: Get account-level configuration.
- GetFindings: List all findings generated by a particular scan.
- GetMetricsSummary: Get top-level account metrics from a specified date.
- GetScan: Get details about a scan, including completion state.
- ListFindingsMetrics: List metrics about all findings within a time range.
- ListTagsForResource: List all tags associated with a scan.
- TagResource: Add one or more tags to a scan.
- UntagResource: Remove one or more tags from a scan.
- UpdateAccountConfiguration: Update account-level configuration with an encryption key.
